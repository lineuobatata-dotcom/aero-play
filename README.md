# Aero Play — versão completa de demonstração

Plataforma web responsiva para celular, com créditos virtuais e sem dinheiro real.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `aero-play`.
2. Envie **todos os arquivos desta pasta** para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde o GitHub publicar o site.

O arquivo inicial é `index.html`, portanto não é necessário servidor ou banco de dados.

## Recursos

- Interface responsiva para celular.
- Saldo inicial de 10.000 créditos virtuais.
- Aero Crash com multiplicador e retirada.
- Jogo Alvo.
- Ranking demonstrativo.
- Histórico local das rodadas.
- Botão para resetar a conta.
- Dados salvos no navegador com `localStorage`.
- Sem pagamentos, depósitos ou saques reais.

Para transformar isso em uma plataforma com contas reais, banco de dados, painel administrativo e outros recursos, será necessário um backend e infraestrutura própria.
